Native NEAR testnet

From allocation to verified payment.

Run a bounded procurement round with real testnet subaccounts and inspect each finalized transfer.

Choose a validation

Each run creates disposable faucet-funded accounts, executes the SDK round, tests journal recovery and checks every transfer against RPC. No mainnet funds or personal wallet required. This validates payments, not delivery of GPU resources or NEAR Intents.

Connecting to the local coordinator…

The public site displays verified evidence. To execute a fresh run, start the local coordinator from the market repository:

npm ci
npm run build
npm run serve

Open the local testnet workspace. Keys remain in the local process; this page does not send requests to an externally hosted signer.
